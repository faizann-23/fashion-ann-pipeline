# Fashion ANN Pipeline (MLOps Assignment 3)

End-to-end ML versioning with Git, DVC and Google Drive.
Fashion-MNIST classification using a fully-connected ANN (TensorFlow).

## Project Structure
- src/prepare.py: download raw data
- src/preprocess.py: normalize and split
- src/train.py: train the ANN
- src/evaluate.py: metrics and confusion matrix
- params.yaml: hyperparameters


## Target
Test accuracy of at least 85 percent.
